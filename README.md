# osTicket Help Desk Lab (Docker)

## Overview
Deployed a fully functional osTicket help desk system using Docker on macOS (M1). This lab demonstrates containerization, database configuration, and ticket workflow testing.

## Technologies
- Docker
- Docker Compose
- MariaDB
- osTicket

## Key Accomplishments
- Built multi-container environment
- Configured database connectivity
- Resolved container errors and environment variables
- Successfully created and managed support tickets
